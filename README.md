# D'SURIA HOSTEL HUB — Phase 2

React + Vite + Firebase project.

## Phase 2 additions
- Student profile form
- Two mandatory emergency contacts
- Super Admin whitelist and role management
- Admin appointment / demotion
- Admin role audit log
- Firestore rules for new collections

## Deploy
1. Replace the existing repository files with this project.
2. Publish the supplied `firestore.rules` in Firebase Console.
3. GitHub Actions builds with `npm install` and `npm run build`.
4. Test Super Admin, Student profile and Emergency Contacts.

Important: these rules are for Phase 2 only. Other hostel modules remain denied until their own rules and code are implemented and tested.
